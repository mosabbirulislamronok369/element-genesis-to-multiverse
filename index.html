GAME RULES

  1. Random Journey uses the verified unique-question bank; a question is never duplicated just to inflate the level count.
  2. Choose a language first; the active language controls question and answer display.
  3. Category Mode creates its own progressive level track.
  4. Select multiple sub-categories; their missions are merged into one category-level pool.
  5. Category level counts are based on actual unique questions available in the selected sub-categories.
  6. Correct answer → Fabricator → discovery → XP → next level.
  7. Previously unlocked Random and Category levels remain replayable.
